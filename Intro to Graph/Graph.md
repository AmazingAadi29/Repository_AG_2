# Graph Algorithms in Python

## Project Overview
This project explores fundamental graph algorithms using Python. It includes the implementation and application of classic algorithms such as Depth-First Search (DFS), Breadth-First Search (BFS), and potentially shortest path algorithms. The goal is to deepen understanding of graph theory by applying these algorithms to structured graph data and analyzing their behavior.

## Technologies Used
- Python
- Google Colab 
- matplotlib

## How to Run
1. Open the notebook in Colab
2. Make sure all required libraries are installed
3. Run each cell in order.

## Challenges Faced
- Implementing recursive algorithms like DFS without causing stack overflows.
- Ensuring graph representations (adjacency lists or matrices) were correctly built.
