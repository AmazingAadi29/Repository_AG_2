# Video Game Sales Prediction

## Project Overview
This project involves analyzing a video game sales dataset and building a predictive model to estimate global sales.The project demonstrates practical use of regression models in real-world data scenarios, specifically within the gaming industry. I could have chosen to do the music dataset but I am a gamer :)

## Technologies Used
- Python 
- Kaggle
- pandas
- numpy
- seaborn
- matplotlib

## How to Run
1. Upload and open the notebook in Kaggle.
2. Ensure the video game sales dataset is added to the Kaggle notebook.
3. Run the cells in order that they are seen in.

## Challenges Faced
- **Missing or inconsistent data**: Several columns (like Year or Publisher) had missing values which required imputation or exclusion.
- **Categorical encoding**: The dataset included categorical features like Platform, Genre, and Publisher, which needed to be encoded properly for modeling.
- **Model selection**: It was important to choose the right regression algorithm and tune it for best performance.

## Future Improvements (we learned a lot of this later)

- Use cross-validation and hyperparameter tuning to improve model reliability.
