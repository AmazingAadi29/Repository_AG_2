# Road Network Analysis

## Project Overview
This project focuses on analyzing a road network graph using real-world data. The goal is to understand how graph theory and network analysis can be applied to transportation systems.
## Technologies Used
- Python
- Google Colab 
- pandas
- matplotlib
- numpy

## How to Run
1. Open the notebook in Google Colab.
2. Make sure the Titanic dataset CSV is available by uploading it manually or by using Google Drive.

## Challenges Faced
- **Graph complexity**: Large or dense graphs took a long time to process.

## Future Improvements
- Analyze dynamic networks (like if new roads were built or more/less traffic were to be observed somwewhere).
- Incorporate additional real-world data like traffic volume or road types.
