# Machine Learning Fundamentals

## Project Overview
This project consists of a collection of hands-on exercises designed to build foundational machine learning skills using housing prices. Each notebook focuses on a specific concept such as data exploration, model validation, underfitting/overfitting, and advanced techniques like random forests (finally)
## Technologies Used
- Python 
- Kaggle
- pandas
- numpy
- matplotlib

## Notebooks Included
- `exercise-explore-your-data.ipynb`
- `exercise-your-first-machine-learning-model.ipynb`
- `exercise-underfitting-and-overfitting.ipynb`
- `exercise-model-validation.ipynb`
- `exercise-random-forests.ipynb`
- `exercise-machine-learning-competitions.ipynb`

## How to Run
1. Upload the notebooks to Kaggle and launch each in the notebook editor.
2. Add the relevant datasets (housing prices) from Kaggle
3. Run the cells in the order that they ppear

## Challenges Faced
- **Overfitting issues**: Early models performed well on training data but poorly on validation data.
- **Interpreting metrics**: Gaining a strong understanding of MAE, RMSE, and other error metrics took practice and experimentation.
