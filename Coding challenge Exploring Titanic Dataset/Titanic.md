# Titanic Survivor Classification
This project tackles the classic Titanic dataset from Kaggle to build a machine learning model that predicts whether a passenger survived the disaster. It begins with detailed data exploration and preprocessing, followed by building classification models using scikit-learn. The aim is to understand what factors most influenced survival and apply supervised learning techniques to generate predictions.

## Technologies Used
- Python
- Google Colab
- pandas
- numpy
- seaborn
- matplotlib

## How to Run
1. Open the notebooks in Google Colab. 
2. Make sure the Titanic dataset CSV is available by uploading it manually or by using Google Drive.

## Challenges Faced
- **Time Challenge**: It was an in class coding challenge with a time limit, so I struggled to complete the project to my best ability and accuracy
- **Handling missing data**: Several key features like 'Age' and 'Cabin' had many missing values. I addressed this by imputing missing values or dropping unhelpful columns.
- **Model tuning**: Achieving good accuracy required experimenting with different classifiers and tuning their hyperparameters.

## Future Improvements  (we learned lots of this later)
- Use more advanced models like Random Forests or XGBoost for improved performance.
- Implement cross-validation so many of the hyperparameters could be tuned better.
